# 汉诺塔求解
### 【问题描述】

设a,b,c是3个塔座。开始时，在塔座a上有一叠共n个圆盘，这些圆盘自下而上，由大到小地叠在一起。各圆盘从小到大编号为1,2,…,n,现要求将塔座a上的这一叠圆盘移到塔座b上，并仍按同样顺序叠置。在移动圆盘时应遵守以下移动规则：
- 规则1：每次只能移动1个圆盘；
- 规则2：任何时刻都不允许将较大的圆盘压在较小的圆盘之上；
- 规则3：在满足移动规则1和2的前提下，可将圆盘移至a,b,c中任一塔座上。

### 【任务要求】

#### 1.	递归算法实现
-	编写一个递归算法，用于求解n（n<=9）层汉诺威塔的移动过程。
-	递归算法应能够清晰地展示每一步的移动指令，包括移动的圆盘编号、源柱子、目标柱子等信息。
-	在递归过程中，实时显示栈的变化过程。
#### 2.	非递归算法实现
-	除了递归算法外，还需要实现一个非递归算法来求解汉诺威塔问题。
-	非递归算法应同样能够生成每一步的移动指令，并实时更新三个柱子上圆盘的状态。
-	比较递归算法和非递归算法的性能，分析各自的优缺点。
#### 3.	图形界面开发
-	开发一个图形用户界面（GUI），用于展示汉诺威塔问题的求解过程。
-	GUI应包含必要的控件，如输入框、按钮和显示区域，以便用户输入n的值并选择算法类型（递归或非递归）。
-	在GUI上动态展示圆盘的移动过程，增强用户的视觉效果和体验。
#### 4.	栈中内容展示
-	显示每一步操作执行时，栈中内容的变化。
